# Eco-Finance / Sustainable Earth

This is Bhavesh Mantrabuddi's portfolio fork of a four-person team project for
**Bitcamp 2025 at the University of Maryland**. The project received the
**Best Sustainability Hack** category award.

- [Devpost submission](https://devpost.com/software/sustainable-earth-eco-finance)
- [Original team repository](https://github.com/KaushalGorla/SustainableEarthy)
- Team: Bhavesh Mantrabuddi, Kaushal Gorla, Suchith Rao, and Yiyang Liu.

The hackathon application combines a React/TypeScript spending dashboard with
Express APIs, transaction normalization, sustainability scoring, and Gemini
recommendations. It also explores rewards and investment visualizations.
See the original README for setup and the full project description.
